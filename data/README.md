# Data

This directory contains the raw and processed data used in the Open Sourcing Mental Health analysis.

## Structure

- `raw/` — original Open Sourced Mental Health survey datasets used by the ETL notebook.
- `processed/` — datasets generated by the analytical pipeline.

## Workflow

Raw OSMH survey data  
→ `1. OSMH ETL.ipynb`  
→ `cleaned_data.csv`  
→ dimensionality reduction  
→ `full_data.csv` and `PC4_loadings.csv`  
→ clustering and segmentation  
→ `clustered_data.csv`  
→ propensity modeling

Raw and processed datasets are excluded from Git. See the README files within each directory for details.
