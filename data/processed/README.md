# Processed Data

Files in this directory are generated by the project notebooks and are not committed to Git.

## `cleaned_data.csv`

Created by `1. OSMH ETL.ipynb`.

Contains the cleaned and harmonized multi-year survey dataset used by exploratory analysis and dimensionality reduction.

## `full_data.csv`

Created by `3. OSMH Dimensionality Reduction.ipynb`.

Contains the analytical dataset with dimensionality-reduction outputs used by clustering and segmentation.

## `PC4_loadings.csv`

Created by `3. OSMH Dimensionality Reduction.ipynb`.

Contains the feature loadings associated with the fourth principal component and is used during propensity-model interpretation.

## `clustered_data.csv`

Created by `4. OSMH Clustering & Segmentation.ipynb`.

Contains cluster assignments and related analytical features used by the propensity-modeling notebook.
